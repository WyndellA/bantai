# BANTAI AI

BANTAI (Behavioral Attention and Non-sleep Tracking with AI) is a computer vision-based web application that detects drowsiness during study sessions using a webcam.

## Features

- Real-time webcam monitoring  

- Eye-state detection (open or closed)  

- Alert system for drowsiness and sleep detection  

- Three alertness states: Awake, Drowsy, Sleeping 


## Tech Stack

- Python  

- TensorFlow (MobileNetV2)  

- OpenCV  

- MediaPipe  

- Streamlit
